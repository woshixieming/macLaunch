# MacLaunch 1.0.8

## Highlights

- Fixed missing Safari icons on macOS installations where Safari is reached through a hidden system Cryptex symlink.
- Added a right-click action to remove app icons from the launcher. Removed icons stay hidden after restarting MacLaunch, and the restore button at the top brings them back.
- Improved drag sorting with before/after insertion indicators and reordering when an icon is dropped.
- Dragging to a page edge now switches pages without changing the app order until an icon is dropped into place.

## Notes

- This release is distributed under the GNU GPL v3.0 or later.
- Removing an icon only hides it from MacLaunch; it does not uninstall the application.
- If an older MacLaunch process is still running, quit it before opening the new build.
